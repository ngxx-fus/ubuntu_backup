## About

- Automation script to setup Ubuntu environment.

## Installation

### Step 1 - Download the script

Download the [UbuntuSetup.sh](UbuntuSetup.sh) script; Update exec right.

```shell
sudo chmod +x UbuntuSetup.sh
```
### Step 2 - Run the script

You need to take your time to read the script, adjust the path, then run:

```shell
./UbuntuSetup.sh
```

At begin of the script, a quick info will be shown, then you can check all installation paths again before continue.
